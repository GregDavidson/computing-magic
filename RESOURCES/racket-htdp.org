* Racket, How to Design Programs, Etc.

** The Racket System

We've been inspired by the [[https://racket-lang.org][Racket System]]
- The excellent Scheme Language core
- The support for /Programming in the Large/
- The ability to create new languages which work together
- the excellent tutorials, especially
  - especially the extraordinary [[https://docs.racket-lang.org/quick][An Introduction to Racket with Pictures]]
    - one of the best ways to start learning Computing Magic!
    - /and now copied by some other languages, e.g. Clojure!/

We recommend engaging with [[https://docs.racket-lang.org/quick][An Introduction to Racket with Pictures]] to
everyone, total beginners, experts and everyone in-between: You'll
have fun and learn a lot!  Be sure to really engage in it:
- try out each example
- create your own variations
Make a second pass looking up interesting or unclear constructs in
- [[https://docs.racket-lang.org/guide][The Racket Guide]]
- [[https://docs.racket-lang.org/reference][The Racket Reference]] - using F1 from DrRacket
- look up what's going on in the Guide and the Reference
